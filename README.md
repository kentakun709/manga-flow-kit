# manga-flow-kit — Codex に渡すだけで広告漫画を作る

縦に読む広告漫画（記事LP）を、Codex が「台本 → キャラの設定画 → コマの絵 → 文字入れ → 1枚に組み立て」まで自分で進めるためのキットです。
何十本も作り直して分かった「文字が崩れない作り方」と「顔がぶれない作り方」を、Codex が読める手順（`AGENTS.md`）にしてあります。

## 使い方（Codex に1回話しかけるだけ）

1. パソコンで Codex（アプリか CLI）を開き、空のフォルダで始める
2. 次の文を、題材の所だけ書き換えて送る

```
https://github.com/kentakun709/manga-flow-kit を clone して、中の AGENTS.md に従って漫画を1本作って。
題材: （例）駅前の新しいパン屋。読む人: 30代の会社員。5コマくらい。
```

まず試したいだけなら、題材の代わりに「見本で試して」と書けば、入っている見本の台本で1本作ります。

手元の記事を漫画にしたい時は、記事のファイルを同じフォルダに置いて「題材: この記事（ファイル名）を漫画にして」と書きます。体験の所だけが漫画になり、説明の所は文のまま残ります。

できあがりは `manga-flow-kit/work/<作品名>/final.png`（横1080px の縦長1枚）です。

見本で作るとこうなります → [docs/見本の仕上がり.jpg](docs/見本の仕上がり.jpg)（5コマ＋黒帯2本。Codex に1回頼んだだけで作った物）

## 要る物

- 画像を作れる Codex（ChatGPT の有料プランでログインした Codex）
- python3（Pillow が無ければ Codex が入れます）
- 1本で画像を10〜20枚作ります（作り直しを含む）。見本は19分でした
- 黒帯の文字用フォントはネットから取ります。取れない時はパソコンに入っている日本語フォントを使うので、そのままで大丈夫です

## 中身

| 場所 | 中身 |
|---|---|
| `AGENTS.md` | Codex が読む手順書（Codex は自動で読みます） |
| `docs/決まり.md` | 崩れない漫画の決まり（話の組み立て・台本の書き方・確かめ方） |
| `templates/script.example.json` | 台本の見本（5コマ・黒帯2本） |
| `refs/` | お手本の画像（画風・文字入れ）。指示に自動で添付される。自分の好きな画風の見本に替えられる |
| `tools/build.py` | 台本から画像の指示文を作る／進み具合を見る／1枚に組み立てる |
| `tools/get_fonts.sh` | 黒帯の文字用フォント（無料）を取る |

作った台本と画像は `work/` に入り、git には載りません。

## 自分の手で動かす時

```
python3 tools/build.py prompts  work/<作品名>   # 台本から指示文と作業の一覧(jobs.md)を作る
python3 tools/build.py status   work/<作品名>   # 何枚できて何枚残っているか
python3 tools/build.py assemble work/<作品名>   # 1枚に組み立てる
python3 tools/build.py flip     work/<作品名> <コマ>          # 絵を左右反転（話す人の左右が逆だった時）
python3 tools/build.py touch    work/<作品名> <コマ> "<直す所>"  # できた画像の1か所だけを直す指示文を作る
```

作り直す時は、台本のそのコマに `"fix": {"art": "…", "letter": "…"}`（直す所を英語で1文）を書いて `prompts` を走らせ直すと、指示文の最後に足されます。
