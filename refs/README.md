# お手本（画像の指示に自動で添付される見本）

`tools/build.py prompts` は、ここにある画像を画像生成の指示に自動で添付する。
文字で画風を説明するより、見本を1枚見せる方が全コマの画風と文字入れが揃う。

| フォルダ | 何のお手本か | 添付される所 |
|---|---|---|
| `style/` | 画風（線の太さ・影の付け方・色・描き込みの量） | 設定画とコマの絵（名前順に最大2枚） |
| `lettering/` | 文字入れ（書体の感じ・吹き出しの形・文字の大きさ・赤字・黒地の心の声・名前札） | 写植（名前順に1枚） |

入っている2枚は、このキットで作った見本漫画のコマから作った物（自前なので自由に使える）。
- `style/style_page.png` … 文字なしのコマ2つ
- `lettering/typo_shelf.png` … 写植済みのコマ2つ（叫び・地の文・名前札・赤字・黒地の心の声が入っている）

指示文には「画風（文字入れ）だけ真似る。顔・構図・台詞は写さない」と必ず書かれる。

## 自分のお手本に替える時

好きな広告漫画の画風に寄せたい時は、その画像を `style/` や `lettering/` に置く（png / jpg / webp）。
名前順で先に来る物が使われるので、`01_` のように番号を付けると確実。置いたら `python3 tools/build.py prompts work/<作品名>` を走らせ直す。

- お手本は「画風の物差し」。顔・キャラクター・台詞を写させない（指示文がそう言う）
- 他の人が作った漫画を置いた時は、そのお手本を公開しない（このフォルダを公開の場所へ上げない）
- 1つの作品の途中でお手本を替えると、そこから画風が変わる。替えるのは作品の最初だけにする
- 自分が前に作った作品の写植済みのコマを `lettering/` に置くと、次の作品も同じ字の感じ（書体・大きさ・器の形）になる
