# 漫画記事LPの決まり（台本を書く前に読む）

広告漫画（記事LP）を何十本も作り直して分かった「こうすると崩れない」の要点。
台本 `script.json` を書く時と、できた画像を確かめる時に使う。

## 1. 一番大事な原則: 絵と文字を同じ1回で描かせない

1回で「絵＋吹き出し＋文字」を出させると、文字は必ず崩れる（書体がぶれる・大きさが暴れる・はみ出す・字が欠ける）。
だから3段に分ける。

1. キャラクターの設定画（1人1枚）… 以後の全コマで同じ顔にするための見本
2. コマの絵（文字も吹き出しも無し）… 文字を置く場所だけ空けておく
3. 写植（2 の絵を添付して、吹き出しと文字を描き足す）… 絵は描き直させない

## 2. 話の組み立て（記事LPの型）

- 冒頭に「変わった後の一瞬」を1コマ見せてから「その、ひと月前。」で過去へ戻ると、読み続けてもらえる
- 流れ: 変わった後 → 困っている毎日 → きっかけ（人・出来事）→ やってみる → 変わった後 → 締め
- 場面が飛ぶ所は黒帯（`"type": "band"`）か、主人公の一人称の地の文（`"kind": "box"`）でつなぐ。コマとコマの間を飛ばさない
- 登場人物の初登場のコマに名前札（`"kind": "label"`、例「佐藤サキ(28)」）を付ける
- 1コマに入れる文字の置き場は1〜3個。4個以上は詰め込みすぎ
- 効き目・効果を言い切る台詞（「必ず痩せる」「治る」等）は書かない。広告の法律に触れる。「私は〜と感じた」の言い方にする

## 3. 台本（script.json）の書き方

- `cast` の `desc` と、各コマの `scene` は**英語**で書く（画像を作るAIへの指示だから）。台詞 `text` は日本語
- `desc` には年齢・髪型・髪の色・目・体格・服を具体的に書く。毎コマ同じ文が入るので、ここが顔の同一性を決める
- `look` は話し手を見分けるための短い英語（例 "the young woman with a short brown bob"）。吹き出しを正しい人に付けるのに使う
- `scene` には「顔をコマのどこに置くか」と「どこを無地の壁・空にするか」を必ず書く。文字の置き場（`pos`）と同じ場所を空ける
- `aspect` は `3:2`（横長）・`2:3`（縦長）・`1:1`（正方形）のどれか
- 文字の置き場 `pos`: `TR`右上・`TL`左上・`R`右・`L`左・`BR`右下・`BL`左下・`TC`上中央・`BC`下中央
- 文字の種類 `kind`:
  - `speech` 台詞。`who` に話し手、`shape` に形（`ellipse`ふつう・`burst`叫び・`thought`考え・`black`心の声＝黒地に白文字）
  - `box` 地の文（白い縦長の四角）
  - `label` 名前札
  - `sfx` 擬音（「ドキッ」等。器なしで大きく）
  - `mono` 器なしの小さなつぶやき
- `size`: `S`小・`M`ふつう・`L`大（叫び・感嘆）
- `|` は縦の列の区切り。**1列5〜7字、12字を超えない**。語の途中で割らない
- 列の頭に「、。…っゃゅょー！？」を置かない
- `《》` で囲んだ所は赤字。**1コマ1か所まで**、伝えたい核心（便益・問題の核心）だけに使う
- 並び順＝読む順。日本の漫画は**右から左・上から下**。先に読ませる台詞を右上に置き、話し手の側に吹き出しを置く（右の人の台詞は右）
- 吹き出しが大きいのを左右交互にすると、目が蛇行して読みやすい

## 4. できた画像の確かめ方（毎枚）

設定画・コマの絵:
- [ ] 文字・吹き出し・ロゴ・透かしが1つも無い
- [ ] 縦横の比が指示どおり
- [ ] 文字の置き場として空けた所が、本当に無地になっている
- [ ] 設定画と同じ人に見える（髪型・髪の色・服・年齢）

写植:
- [ ] 台詞が `expected/<コマ>.txt` と**一字一句同じ**（欠字・化け・余計な字が無い）
- [ ] 吹き出しが顔・目・口・手を隠していない
- [ ] 吹き出しが正しい話し手の側にある
- [ ] 縦書きで、右の列から読む順になっている
- [ ] 赤字は指定した所だけ
- [ ] 絵そのものが描き変わっていない

だめな時は、同じ指示文で**1回だけ**作り直す。2回だめなら `scene` か台詞を短く直してから作り直す（同じ指示文で何度も回さない）。

## 5. 画像を作るAIの癖（分かっている物）

- 寝ている・横たわる・シーツの絵は安全の判定で断られやすい。座った姿・服を着た姿に変えると通る
- 顔がぶれる時は、設定画に加えて「できの良い既存のコマ」を1枚添付すると収まる
- 吹き出しを絵の段で描かせると、中に偽の文字が入る。絵の段では描かせない（この道具の指示文はそうなっている）
- 細い字・長い台詞ほど崩れる。台詞は短く、1つの器に3〜4列まで
- 文字の置き場の空け方は、角を1つ指すより「上半分は何も無い壁」「人物は小さく中央、頭は真ん中の線より下」のように広く言い切る方が通る。2人のコマは引きの絵（wide shot）にする
- 赤字の直後に黒字の助詞を続けると（例 《楽しみ》に）赤がにじむ。赤字は語の切れ目で閉じ、黒字の続きは別の列にするか削る
